# История изменений

## 0.4.0 — ноябрь 2026

### PDF
- «Номера»: номер внизу каждой страницы (`1` или `1 / N`), слева, по центру или справа;
  работает и на повёрнутых страницах.
- «Пароль»: защита документа на открытие (AES-256) и «Снять пароль» для защищённых файлов.
  Пароль не сохраняется на диск и не попадает в историю задач.
- Библиотека `cryptography` добавлена в зависимости (нужна для шифрования).

### Автоматизация
- «Горячая папка» (`MEDIAHUB_WATCH_DIR`): файлы, брошенные в папку, обрабатываются сами;
  результаты, исходники и сбои раскладываются по подпапкам.
- Включается и выключается из меню значка в трее; пункт «Открыть горячую папку».
- Файл `.env` теперь действительно читается (переменные `MEDIAHUB_*`).

### Интерфейс
- Свои наборы настроек для картинок: «+ Сохранить набор», удаление крестиком, хранятся в браузере.
- Когда обработка закончилась в фоновой вкладке: в заголовке появляется «✓ Готово»,
  а по кнопке «Уведомлять о готовности» в подвале – системное уведомление.
- Семь действий PDF переносятся на вторую строку на узких экранах.
- Пояснения к настройкам («Номера через запятую…», «Порядок файлов…») теперь тихой подписью
  под карточкой настроек, а не плашкой над списком файлов: страница больше не «прыгает».
- На телефоне убрана бесполезная подсказка про Ctrl+V и «висящая» точка рядом с ней.
- verify/browser_flows.py: сквозная проверка 25 сценариев в настоящем браузере, в том числе
  по IP-адресу (как с телефона), со страницей приёма файлов.

## 0.3.0 — ноябрь 2026

### Новые операции
- Картинки → один PDF: страница по размеру картинки или лист A4 с полями; порядок –
  стрелками ↑↓ или перетаскиванием.
- PDF: «Страницы» (оставить «1-3, 5, 8-», удалить, повернуть) и «Разбить» на отдельные
  PDF по странице.
- Звук: MP3, M4A, OGG, WAV, FLAC и выравнивание громкости (EBU R128).
- Подпись (водяной знак) в правом нижнем углу картинки.
- Видео и звук: плеер над настройками с кнопками «Начало здесь» / «Конец здесь».

### Windows
- Пункт «Отправить → MediaHub» в меню Проводника: включается в меню значка в трее
  или при установке; файлы сразу появляются в окне MediaHub.
- build-windows.cmd – сборка приложения и установщика одним файлом.
- setup-git.cmd – чистка проекта и подключение Git.

### Надёжность
- Готовые задачи переживают перезапуск сервера (итог хранится в job.json сессии).
- Стили сведены по разделам без изменений во внешнем виде (проверено попиксельно).

## 0.2.0 — ноябрь 2026

### Интерфейс
- Новый дизайн в стиле Apple: сгруппированные списки, сегментированные переключатели,
  тёмная тема, лист с QR-кодом.
- Английский язык интерфейса (переключатель внизу страницы); сервер отвечает
  сообщениями на языке интерфейса.
- Результат по каждому файлу с размерами «было → стало» и «Скачать всё» архивом.
- Шторка «до / после» для одной картинки.
- «Недавние» и последние настройки сохраняются между перезагрузками страницы.
- Прогресс загрузки с процентами и скоростью, отмена во время загрузки.
- «Копировать картинку» — результат сразу в буфер обмена.
- «Сохранить в папку» (Загрузки\MediaHub) и «Показать в папке».
- Порядок склейки PDF кнопками ↑↓ (работает на телефоне).
- Новая страница отправки файлов с телефона с прогрессом.

### Обработка
- Форматы AVIF и HEIC на выходе (если их умеет кодировать Pillow).
- Поворот и кадрирование по центру: 1:1, 4:5, 3:2, 16:9, 9:16.
- Обрезка звука и видео по времени (начало и конец), начало фрагмента для GIF.
- Степень сжатия PDF: слабое, среднее, сильное.

### Надёжность и безопасность
- Отмена реально останавливает FFmpeg; статус «отменено» не перезаписывается.
- «Бомбы распаковки» отклоняются понятной ошибкой вместо 500.
- Непредвиденные ошибки не рвут соединение.
- Ограничение частоты запросов не действует на сам компьютер (только на устройства
  из сети, 60 в минуту, MEDIAHUB_RATE_LIMIT).
- Приём с телефона: одноразовый ключ в QR-коде, лимиты размера и числа файлов.
- Токен доступа поддерживается интерфейсом и QR-кодами.
- Нагрузочная проверка verify/stability.py: 60+ сценариев, 400 задач подряд.

### Windows
- Значок в трее: «Открыть», «Запускать при входе в Windows», «Выход»; второй запуск
  открывает уже работающий сервер.
- start.cmd сам находит рабочий Python, создаёт .venv, перезапускает зависший сервер.
- Сборка приложения (tools/build_exe.py) с FFmpeg внутри и установщик Inno Setup.
- FFmpeg больше не открывает консольные окна.
